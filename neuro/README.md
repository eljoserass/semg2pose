# Getting Neurosciency (interactive page)

Source of the claude.ai artifact that explores whether the low-dimensional structure of hand pose is already present
in the muscle signal. Open `index.html` through a local web server (`python -m http.server` in this folder).
`data.json` holds results exported from `notebooks/neural_synergies.ipynb`; `figs/` are figures from
`cross_user_invariance`, `network_internals` and `intermuscular_coherence`. Spanish and English text live side by side
(`data-l="es"` / `data-l="en"`).
