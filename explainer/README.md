# De la EMG a la mano (interactive guide)

Source of the interactive guide published as a claude.ai artifact. Open `index.html` through a local web server
(e.g. `python -m http.server` in this folder), since it fetches `data.json`, `en.json` and `fr.json`.

- `data.json`, `hands/`: real-data snippets and hand renders, generated by `scripts/export_explainer_data.py`.
- `figs/`: figures from `scripts/make_deck_figures.py`.
- `en.json`, `fr.json`: translations keyed by the `data-i18n` attributes in `index.html` (Spanish is the default text).
